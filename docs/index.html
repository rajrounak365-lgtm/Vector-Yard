How To Play

Four Rules.
Infinite Puzzles.

01
Tap a Snake

Click any arrow on the grid to attempt to move it.

02
Clear Path = Exit

If the arrow's path to the edge is free, it slithers off the grid.

03
Blocked = Lose a Life

Tapping a snake that is blocked costs you a ❤️. Lose all 3 and the level restarts.

04
Clear the Grid

Remove every snake from the board to win and advance to the next level.
