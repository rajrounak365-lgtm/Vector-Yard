# Vector Yard — Arrow Chain Puzzle

**Untangle. Escape. Win.**

A dense grid of winding arrow-snakes stands between you and victory. Study the tangle, find the exit order, and clear every last one in this puzzle game!

![Arrow Chain Puzzle](https://img.shields.io/badge/Game-Arrow%20Chain-0071e3?style=for-the-badge)

## 🎮 How to Play

Four simple rules govern this puzzle:
1. **Tap a Snake**: Click or tap any arrow on the grid to attempt to move it.
2. **Clear Path = Exit**: If the arrow's path to the edge is free, it slithers off the grid. Look for snakes whose arrowhead points toward an empty lane all the way to the edge.
3. **Blocked = Lose a Life**: Tapping a snake that is blocked by another snake costs you a ❤️. Lose all 3 hearts, and the level restarts!
4. **Clear the Grid**: Remove every snake from the board to win and advance to the next level.

## ✨ Features

- **Infinite Procedural Levels**: The game features an endless procedural engine. Every generated puzzle is mathematically guaranteed to have at least one valid solution.
- **Custom Level Editor**: Built right into the game! Click the "✏️ Level Editor" button to draw your own snake puzzles, playtest them, and generate a shareable link.
- **Responsive & Touch-Friendly**: Precise and smooth interactions for both desktop mice and mobile touch screens.
- **Built-in Sound Engine**: Minimalist Web Audio API sound effects with zero external audio assets.
- **Dark Mode**: Toggle between light and dark themes anytime.

## 🚀 Running the Game

Because the game is entirely self-contained within a single HTML file, there are no dependencies to install!

1. Simply open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
2. Enjoy the puzzle!

## 🛠️ Level Editor Usage

1. Click the **✏️ Level Editor** button at the bottom right.
2. **Draw Mode**: Click & drag across the grid to draw a snake. The start of your drag becomes the tail, and the end becomes the head (arrow).
3. Click an existing snake to delete it.
4. Adjust the grid size using the `+ Row`, `- Row`, `+ Col`, and `- Col` buttons.
5. Click **▶ Play Test** to try your level out.
6. Click **🔗 Share Link** to copy a unique URL that automatically loads your custom level for anyone who opens it!
